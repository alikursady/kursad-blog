# Arşiv: "tuval" ana sayfası (gece fotoğrafı + geri sayım)

Ekim–Kasım 2026 arasında ana sayfada duran tam ekran gece fotoğrafı,
fener / yağmur / şimşek efektleri ve geri sayım buraya kaldırıldı.
Bu klasör Hugo tarafından okunmaz, siteye hiçbir şey yayınlanmaz.

| Dosya | Eski yeri |
| --- | --- |
| `header-tuval.html` | `layouts/_partials/header.html` dosyasının en üstündeki blok |
| `tuval.css` | `assets/css/tuval.css` |
| `tuval.js` | `assets/js/tuval.js` |
| `images/` | `static/images/tuval/` |
| `fonts/` | `static/fonts/` (yalnızca bu tasarımın kullandığı Jost yazı tipi) |

Geri getirmek için dosyaları eski yerlerine taşıyıp `header-tuval.html`
içeriğini `header.html` dosyasının başına eklemek yeterli.
